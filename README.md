# 旷野厨房 · 塞尔达传说：旷野之息料理与食谱查询

**Zelda: Breath of the Wild Kitchen · BOTW Cooking, Elixirs & Rupee Planner**

**手里的材料能煮什么？怎么搭配来吃，怎么搭配来卖？**

为《塞尔达传说：旷野之息》玩家制作的料理、药剂与卢比搭配工具。把材料放进五格锅里，查看成品、效果与售价；也可以搜菜名，直接试一份最简配方。

给林克准备补血料理、恢复精力的食谱，或耐寒、防火、提升攻击力的搭配，都可以先在这里试一锅；想赚卢比，也能按手头材料比较料理和药剂的出售价格。

## 可以帮你做什么

| 你想知道 | 可以这样用 |
| --- | --- |
| 这些材料放一起，会做出什么？ | 自由加入最多5份，实时查看料理或药剂名称、增益与售价；投错也会显示失败料理。 |
| 记得菜名，但忘了配方？ | 首页同一个搜索框查材料与菜名，支持中文简称、拼音与首字母；选菜名装入最简配方。 |
| 捡到虫子或怪物材料，不知道怎么配？ | 加入锅里后点“食用搭配”，查看需要补什么、能得到什么效果。 |
| 想把手头材料换成更多卢比？ | 点“卖钱搭配”，按售价从高到低比较；选择自己有的材料及数量，筛出能做的方案。 |
| 想知道具体收益？ | 查看红心、额外黄心、精力圈数、效果等级与时间；可按自己的红心上限计算。 |

## 三步试一锅

1. 搜索材料或菜品，也可以通过分类和效果筛选寻找。
2. 用加减按钮调整数量，查看“我的锅”里的预计结果。
3. 需要灵感时打开“食用搭配”或“卖钱搭配”，选方案补入锅里；不满意可以撤销。

手机、平板、电脑都可以使用，无需注册账号。

## 关于自有材料与计算范围

- 自有材料清单自动保存在当前浏览器，正常刷新保留；清理网站数据、更换浏览器或设备不会自动同步。
- “卖钱搭配”保留当前锅内材料，计算最多5份的一锅，最多展示当前条件下的前60种成功搭配；不是整个背包的多锅出售计划。模拟不会扣库存。
- “食用搭配”提供经计算器校验的候选方案；新增三种及以上材料的推荐不保证覆盖全游戏每一种组合。
- 大成功与怪物精华存在随机结果，页面区分普通结果和可能分支。各项最大值不一定同时出现。
- 当前计算锅煮，不提供火边烧烤、冰冻或温泉加工模式。

规则经过自动检查与交叉比对，但没有在游戏里逐锅验证所有组合。如果遇到差异，欢迎附上材料、数量、烹饪条件和游戏截图反馈。
